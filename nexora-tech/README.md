# Nexora Tech

Catálogo/e-commerce fictício de hardware construído exclusivamente com HTML5, CSS3 e JavaScript puro.

## Como executar

Abra `index.html` em um navegador moderno. Não há dependências, backend ou etapa de build.

## Recursos

- 24 produtos em seis categorias; busca, filtros e ordenação dinâmicos.
- Carrinho, favoritos e sessão de usuário persistidos em `localStorage`.
- Cadastro, login/logout, modal de produto, drawer de carrinho e notificações.
- Interface responsiva e acessível com navegação por teclado.

> **Nota de segurança:** as senhas são salvas em `localStorage` exclusivamente para demonstração frontend. Em produção, use autenticação de servidor e senhas armazenadas com hash seguro.
